# Tours & Travels Booking & Sales Analytics Dashboard 📊

## 📌 Project Overview

This project is an **interactive Power BI Tours & Travels Booking & Sales Analytics Dashboard** created to analyze travel booking data and transform raw business data into meaningful and actionable insights.

The dashboard provides a comprehensive view of **booking performance, revenue generation, traveler volume, destinations, package types, booking status, payment methods, monthly trends, and salesperson performance**.

The project demonstrates the practical use of **Microsoft Power BI** for data analysis, business intelligence, KPI development, interactive visualization, filtering, and dashboard design.

> Note: This project is created as an academic/practical Data & Business Analytics project to demonstrate Power BI data analysis and dashboard development skills.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze overall Tours & Travels booking performance
- Calculate important Key Performance Indicators (KPIs)
- Analyze total revenue generated from travel bookings
- Analyze the number of travelers
- Calculate average booking value
- Track confirmed bookings
- Analyze revenue by destination
- Analyze bookings by package type
- Analyze booking status distribution
- Analyze monthly revenue and booking trends
- Analyze different payment methods
- Analyze salesperson performance
- Provide interactive filtering for detailed analysis
- Create a professional and easy-to-understand Power BI dashboard

## 📈 Dashboard Visualizations

The dashboard contains multiple interactive visualizations to analyze different aspects of the travel business.

### Revenue by Destination

A bar chart is used to analyze **total revenue generated by different destinations**.

This helps compare destination-wise revenue performance and understand the contribution of different travel destinations.

---

### Package Type-wise Bookings

A column chart displays the **number of bookings by package type**.

This helps analyze customer preferences across different travel packages.

---

### Booking Status

A donut chart provides a visual breakdown of bookings based on their status.

The analysis includes categories such as:

- Confirmed
- Pending
- Cancelled

This helps understand the overall distribution of booking outcomes.

---

### Monthly Revenue & Bookings

A combination chart analyzes:

- Monthly Revenue
- Number of Bookings

The visualization helps identify monthly changes and trends in travel business performance.

---

### Payment Method

A donut chart analyzes the distribution of bookings across different payment methods.

The dashboard includes payment methods such as:

- Cash
- Credit Card
- UPI
- Net Banking

This helps understand customer payment preferences.

---

### Salesperson Performance

A bar chart analyzes **revenue generated by individual salespersons**.

This provides a clear comparison of salesperson contribution to overall travel revenue.

---

## 🎛️ Interactive Slicers

- 📅 Month

- 📍 Destination
- 💼 Package Type
- 📝 Booking Status
- 💳 Payment Method
- 👥 Salesperson

Users can select one or multiple filter values to dynamically explore specific parts of the dataset.
